## 1. 💡 서론: 개발 공부를 시작한 당신이 제일 먼저 마주치는 3가지 벽

프로그래밍 공부를 처음 시작하면 문법(Python, JavaScript 등)을 배우기도 전에 생소한 용어와 도구들에 턱 막히곤 합니다.

* *"검은 화면(터미널)에 커서만 껌빡이는데 뭘 입력해야 하지?"*

누구나 처음엔 겪는 당연한 과정입니다! 본 아티클은 **초보 개발자가 가장 기본적으로 알아야 할 터미널, Git, 그리고 AI 도구 활용법**을 가장 쉬운 언어로 정리해 드립니다.

## 2. 💻 1. 검은 화면이 무섭지 않은 터미널 기초

### 1.1 왜 마우스 대신 검은 화면(터미널)을 쓸까?
우리가 평소 윈도우 탐색기나 맥 Finder에서 폴더를 클릭하고 파일을 생성하는 행동은 모두 **GUI(그래픽 사용자 인터페이스)**입니다. 

반면 **터미널(CLI, 명령줄 인터페이스)**은 명령어 몇 줄로 복잡한 파일 이동, 프로그램 실행, 서버 관리를 마우스보다 10배 이상 빠르게 처리해 줍니다. 개발 도구(Git, AI 에이전트, 백엔드 서버)의 대부분이 터미널 기반으로 작동하기 때문에 익숙해지는 것이 좋습니다.

### 1.2 외워두면 평생 쓰는 필수 명령어 5가지

| 명령어 | 뜻 | 윈도우/맥 비유 | 사용 예시 |
| :--- | :--- | :--- | :--- |
| **`pwd`** | Print Working Directory | "지금 내가 어느 폴더에 있지?" 확인 | `pwd` |
| **`ls`** (또는 `dir`) | List | 현재 폴더 안의 파일/폴더 목록 보여주기 | `ls` |
| **`cd`** | Change Directory | 다른 폴더로 이동하기 | `cd my-folder` |
| **`mkdir`** | Make Directory | 새 폴더 만들기 | `mkdir project` |
| **`clear`** (또는 `cls`) | Clear | 터미널 화면 깨끗하게 지우기 | `clear` |

> 💡 **Tip**: 폴더 이름이나 파일 이름을 칠 때 앞글자 몇 개만 치고 **`Tab` 키**를 누르면 자동으로 이름이 완성됩니다!

## 3. 🐙 2. Git과 GitHub, 개념부터 헷갈리지 않게 잡아보기

### 2.1 Git과 GitHub의 차이점
* **Git (깃)**: 내 컴퓨터에 설치하는 **'타임머신 소프트웨어'**입니다. 코드의 변경 이력(버전)을 기록해 줍니다.
* **GitHub (깃허브)**: 인터넷에 있는 **'코드 구글 드라이브/클라우드'**입니다. Git으로 기록한 타임머신 기록을 인터넷에 백업하고 남들과 공유합니다.

### 2.2 `add` ➔ `commit` ➔ `push` 3단계 흐름 완벽 이해

코드를 작성하고 GitHub에 올리는 과정은 **"장보기와 배송"**에 비유할 수 있습니다.

```
[내 작업 공간 (Working Directory)]
        │  `git add` (장바구니에 담기)
        ▼
[임시 저장소 (Staging Area)]
        │  `git commit -m "메시지"` (상자에 포장하고 라벨 붙이기)
        ▼
[내 로컬 Git 저장소 (Local Repository)]
        │  `git push origin main` (트럭으로 GitHub 구글드라이브에 배송)
        ▼
[GitHub 웹사이트 (Remote Repository)]
```

1. **`git add 파일명`**: 변경한 파일 중 저장할 것들을 **장바구니(Staging Area)**에 담습니다. (전체 담기는 `git add .`)
2. **`git commit -m "로그인 기능 추가"`**: 장바구니에 담긴 변경 사항을 **설명 메시지와 함께 하나의 버전으로 포장**합니다.
3. **`git push origin main`**: 내가 만든 커밋 상자들을 **인터넷 GitHub 저장소로 배송(업로드)**합니다.

## 4. 🤖 3. 2026년 AI 코딩 도구, 스마트하게 질문하는 첫걸음

### 3.1 AI에게 통째로 작성 맡기기 vs 질문하며 함께 짜기
2026년 현재 ChatGPT, Claude, Cursor 등 AI 도구가 매우 강력해졌습니다. 하지만 초보자 때 **"로그인 페이지 코드 전체 다 짜줘"**라고 요청하고 복사-붙여넣기만 하면, 에러가 났을 때 스스로 수정할 수 없게 됩니다.

#### ❌ 나쁜 질문 방식:
> *"HTML/CSS/JS로 인스타그램 클론 코딩 코드 전부 다 짜줘."*

#### ⭕ 좋은 질문 방식 (단계별 질문):
> *"자바스크립트에서 버튼을 클릭했을 때 숫자가 1씩 증가하는 카운터 기능을 만들고 싶어. `addEventListener` 함수를 사용하는 기초 예시 코드와 설명을 작성해 줄래?"*

### 3.2 초보자를 위한 AI 활용 꿀팁 3가지
1. **에러 메시지 그대로 붙여넣기**: 빨간색 에러 문구가 뜨면 당황하지 말고 에러 메시지를 통째로 복사해서 *"이 에러가 왜 발생하는지 원인과 해결 방법을 알려줘"* 라고 물어보세요.
2. **"주석 달아줘" 요청하기**: AI가 준 코드가 이해되지 않는다면 *"이 코드의 한 줄 한 줄마다 쉬운 설명 주석(Comment)을 달아줘"* 라고 하세요.
3. **AI 환각(Hallucination) 주의**: AI가 존재하지 않는 함수나 라이브러리를 만들어낼 때가 있습니다. 반드시 코드를 직접 실행해 보며 검증해야 합니다.

## 5. 🎯 4. 마무리: 완벽함보다 꾸준함이 중요한 이유

개발을 처음 시작할 때 모든 명령어와 문법을 외우려고 할 필요는 없습니다.  
현업 개발자들도 매일 Google 검색과 AI 도구를 활용하며 에러를 고칩니다.

* 하루에 명령어 1~2개씩 익혀보기
* 작은 코드라도 Git에 커밋해 보는 습관 들이기
* 막히는 에러를 만났을 때 해결 과정을 기록해 보기

이 3가지만 꾸준히 실천한다면 여러분도 빠르게 멋진 개발자로 성장할 수 있습니다.
